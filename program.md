# Programme Westside Rugby Masters 38 ans

## 📅 Aperçu
- **Durée totale** : 6 mois (24 semaines) — Novembre 2025 à Mai 2026
- **Objectif global** : Préparation rugby compétition Mai 2026 avec développement force maximale et explosivité
- **Nombre de phases** : 6 phases
- **Style d'entraînement** : Westside Conjugate Method adapté Masters + Rugby-Specific Conditioning
- **Fréquence** : 3 jours/semaine (Lundi-Mercredi-Vendredi)
- **Durée séances** : 40-60 minutes
- **Contraintes** : Post-labrum épaule (10 ans), hanche récupérée, Masters 38 ans

---

## 📂 Phases

### Phase 0 — Retour Progressif
- **Objectif** : Réadaptation post-arrêt, établir baseline 1RM, technique parfaite
- **Durée** : 4 semaines (Décembre 2025)
- **Contenu principal** : Progression charges graduelles, patterns moteurs, conditionnement base
- **Points clés** : 
  - Pas de Westside encore (établir fondations)
  - Tests 1RM semaine 4
  - Mobilité épaule quotidienne 20 min
  - Aucune douleur tolérée

### Phase 1 — Base Force + Introduction Westside
- **Objectif** : Introduction méthode conjugate, développement force base
- **Durée** : 4 semaines (Janvier 2026)
- **Contenu principal** : Pattern ABAB, Max Effort + Dynamic Effort, rotations 3 semaines
- **Points clés** :
  - Premier vrai cycle Westside
  - Rotations exercices simplifiées (3 au lieu de 6-9)
  - Établir vitesse barbell 0.7-0.8 m/s
  - Volume réduit Masters (3-4 accessoires)

### Phase 2 — Force Maximale Westside
- **Objectif** : Peak force absolue, intensification conjugate
- **Durée** : 4 semaines (Février 2026)
- **Contenu principal** : ME 90-95%, DE 70-80%, accessoires augmentés
- **Points clés** :
  - Intensité maximale phase
  - Viser PRs sur tous ME
  - Volume légèrement augmenté (4-5 accessoires)
  - Deload semaine 4 obligatoire

### Phase 3 — Westside + Rugby Hybride
- **Objectif** : Maintien force, développement MAS et patterns rugby
- **Durée** : 4 semaines (Mars 2026)
- **Contenu principal** : ME/DE réduits + GPP Rugby, MAS intervals, AMRAP rugby
- **Points clés** :
  - Intégration conditionnement rugby
  - Westside 2 jours, Rugby WOD 1 jour
  - MAS 4×4 min @ 85-90%
  - Maintien force @ 95-100% février

### Phase 4 — Peak Performance
- **Objectif** : Pic performance absolue
- **Durée** : 4 semaines (Avril 2026)
- **Contenu principal** : ME réduit, DE qualité, conditioning rugby intensifié
- **Points clés** :
  - Volume réduit (-30%), intensité maintenue
  - Focus qualité mouvement
  - Tests performance semaine 3
  - Préparation saison

### Phase 5 — Compétition
- **Objectif** : Maintien qualités, performance rugby optimale
- **Durée** : 4 semaines (Mai 2026)
- **Contenu principal** : Dynamic Effort seulement, GPP léger, récupération
- **Points clés** :
  - Éliminer Max Effort (trop taxant CNS)
  - 2 jours/semaine maximum
  - Récupération priorité absolue
  - Performance rugby > gym

## 🏋️ Catalogue des Exercices

### MOUVEMENTS PRINCIPAUX

#### Trap Bar Deadlift
- **Catégorie** : Lower
- **Type** : Max Effort / Test
- **Description** : Deadlift avec trap bar (barre hexagonale) du sol
- **Points techniques** :
  - Départ mi-tibias pour protection hanche
  - Poignées hautes si disponible
  - Hanche dominante, colonne neutre stricte
  - Respiration : Inspirer avant, expire au lockout
- **Progressions** : 5RM Déc → 1RM Jan → PR Fév
- **Variations** : Deficit (sur blocs 5-10cm), standard sol

#### Box Squats
- **Catégorie** : Lower
- **Type** : Dynamic Effort principal
- **Description** : Squat sur box avec pause
- **Points techniques** :
  - Box à parallèle ou juste au-dessus
  - S'asseoir sur box (ne pas toucher légèrement)
  - Pause 1 sec complètement détendu
  - Explosion violente remontée
  - Maintenir tension core
- **Progressions Wave** : 10×2 @ 65% → 8×2 @ 70% → 6×2 @ 75%
- **Variations** : Safety Bar, barre haute, barre basse

#### Floor Press Haltères
- **Catégorie** : Upper
- **Type** : Max Effort principal
- **Description** : Press allongé au sol avec haltères
- **Points techniques** :
  - Allongé au sol, genoux pliés pieds au sol
  - Coudes touchent sol = ROM limitée (protection épaule)
  - Pause 1 sec coudes au sol
  - Press explosif lockout complet
  - Contrôle descente 2-3 sec
- **Progressions** : 3RM Déc → 1RM Jan → PRs rotation
- **Variations** : Close grip, incline floor press, tempo

#### Goblet Squats
- **Catégorie** : Lower
- **Type** : Accessory / Test
- **Description** : Squat tenant haltère devant poitrine
- **Points techniques** :
  - Haltère vertical contre poitrine
  - Coudes entre genoux en bas
  - ROM complète ass-to-grass
  - Core serré
- **Usage** : Échauffement, test max reps, accessoire volume

### MOUVEMENTS DYNAMIC EFFORT

#### Floor Press Speed
- **Catégorie** : Upper
- **Type** : Dynamic Effort
- **Description** : Floor press 9×3 @ 60-70% focus vitesse
- **Points techniques** :
  - Même technique que ME floor press
  - Vitesse explosive prioritaire
  - Pas de pause longue au sol
  - Viser 0.8 m/s si mesurable
- **Wave** : 9×3 @ 60% → 9×3 @ 65% → 6×3 @ 70%

### ACCESSOIRES PRINCIPAUX

#### Kettlebell Swings
- **Catégorie** : Full Body / Lower dominant
- **Type** : Accessory Power
- **Description** : Swing explosif kettlebell
- **Points techniques** :
  - Charnière hanche (pas squat)
  - Extension explosive hanches
  - Hauteur poitrine/épaules
  - Abs tight au sommet
- **Progressions** : 16 kg → 24 kg → 30 kg
- **Volume typique** : 4×12-15

#### Face Pulls
- **Catégorie** : Upper
- **Type** : Accessory / Prehab
- **Description** : Tirage bandes vers visage
- **Points techniques** :
  - Ancrage hauteur tête
  - Tirer vers visage (pas clavicules)
  - Rotation externe finale
  - Squeeze scapulae
- **Usage** : Quotidien possible, santé épaule
- **Volume typique** : 3-4×15-20

#### Sandbag Shouldering
- **Catégorie** : Full Body
- **Type** : Accessory Power / Rugby-specific
- **Description** : Sol à épaule avec sandbag
- **Points techniques** :
  - Bear hug sandbag
  - Explosion hanches
  - Rotation corps pour épauler
  - Alterner épaules
- **Charges** : 30 lbs léger, 100 lbs lourd
- **Volume typique** : 4×6 par épaule

#### Farmers Walk
- **Catégorie** : Full Body
- **Type** : Accessory Strength / GPP
- **Description** : Marche avec charges lourdes
- **Points techniques** :
  - Posture droite, épaules tirées arrière
  - Core serré
  - Marche contrôlée
  - Ne pas laisser tomber épaules
- **Progressions** : 20 lbs → 35 lbs → 55 lbs par main
- **Volume typique** : 4×20-25m

### CONDITIONNEMENT

#### Air Bike Intervals
- **Catégorie** : Conditioning
- **Type** : MAS / HIIT
- **Description** : Intervals haute intensité Air Bike
- **Formats** :
  - Phase 0-1 : Continu 20-25 min @ 65-70%
  - Phase 3 : 4×4 min @ 85-90% / 2 min repos
  - Phase 4 : 6×45 sec sprint / 90 sec repos
- **Tracking** : Calories par intervalle

#### Battle Rope Waves
- **Catégorie** : Conditioning / Upper
- **Type** : HIIT / GPP Rugby
- **Description** : Waves explosives avec battle rope
- **Variations** :
  - Alternating waves
  - Double waves (tsunami)

  - Slams

### RUGBY-SPECIFIC

#### AMRAP Rugby Circuit
- **Description** : Circuit max rounds temps donné
- **Format typique 25 min :**
  - Trap bar × 5 @ 75%
  - KB swings × 15
  - Battle rope × 20
  - Burpees × 5
  - Air Bike × 10 cal
- **Objectif** : Max tours, noter nombre

#### MAS Intervals 4×4
- **Description** : Maximal Aerobic Speed intervals
- **Format** : 4 × 4 min @ 85-90% FCmax / 2 min récupération
- **Équipement** : Air Bike, rowing, ou circuit

## 🧠 Notes Importantes

### RÉCUPÉRATION

**Entre Séances :**
- **72-96h** entre même mouvement principal obligatoire
- Pattern ABAB assure cela naturellement
- Si fatigue excessive : ajouter jour repos

**Intra-Séance :**
- Max Effort : 3-5 min séries lourdes (90%+)
- Dynamic Effort : 60 sec séries (focus récupération partielle)
- Accessoires : 60-90 sec selon exercice

**Hebdomadaire :**
- Deload **semaine 4** chaque phase NON-NÉGOCIABLE
- Volume -30%, intensité -10%
- Maintien qualité mouvement

**Quotidienne :**
- **Sommeil : 7-9h** minimum (coucher 20h-21h pour réveil 4h30)
- **Mobilité épaule : 20 min** (10 matin + 10 soir)
- **Mobilité hanche : 10 min** prévention
- **Nutrition optimale** : Plan fourni précédemment

### PRÉVENTION BLESSURES

**Épaule Post-Labrum :**
- ❌ **Jamais** : Behind-neck press, bench press barbell lourd, bras derrière plan frontal
- ✅ **Toujours** : Haltères > barbell, ROM respectée, mobilité quotidienne
- 🚨 **Signaux arrêt** : Douleur aiguë, sensation accrochage, instabilité
- **Test hebdomadaire** : Rotation externe passive - si douleur = ajuster programme

**Hanche (Prévention Récidive) :**
- ✅ **Mobilité quotidienne** : 90/90, hip CARs, cossack squats
- ✅ **Échauffement prolongé** : 10 min minimum jamais skipper
- 🚨 **Signaux arrêt** : Douleur sciatique >1/10, raideur matinale
- **Si symptômes** : Retour mobilité intensive, réduire charges

**Masters 38 ans :**
- **Inflammation** : Oméga-3, anti-inflammatoires naturels
- **Articulations** : Glucosamine, collagène si besoin
- **Récupération** : Massage 2×/mois, foam rolling quotidien
- **Écoute corps** : Ajuster même si plan dit autre chose

### MODIFICATIONS POSSIBLES

**Si Douleur Épaule :**
- Remplacer overhead par alternatives
- Augmenter incline press (moins stress)
- Floor press toujours sécuritaire
- Réduire ROM si nécessaire

**Si Fatigue Excessive :**
- Passer semaine B en deload
- Réduire accessoires 3→2
- Augmenter repos ME à 72h+
- Éliminer 1 séance/semaine temporairement

**Si Progression Stagne :**
- Vérifier nutrition (calories suffisantes?)
- Vérifier sommeil (7-9h?)
- Deload immédiat si >2 semaines stagnation
- Changer variations ME plus fréquemment

**Si Manque Temps :**
- Réduire accessoires à 2-3 essentiels
- Combiner exercices (supersets)
- Réduire échauffement à 7 min strict
- Maximum efficacité 45 min

**Vacances/Imprévus :**
- 1 semaine off : Reprendre même intensité
- 2 semaines off : -10% intensité, volume normal
- 3+ semaines : Retour Phase 0 modifiée

### SIGNAUX SUCCÈS

✅ **PRs réguliers** sur Max Effort (au moins 1 par 3 semaines)
✅ **Vitesse maintenue** Dynamic Effort (0.7-0.8 m/s)
✅ **Récupération 48h** suffisante (pas fatigue résiduelle)
✅ **Zero douleur** hanche/épaule pendant entraînements
✅ **Progression conditioning** (calories, tours, temps)
✅ **Technique maintenue** sous fatigue
✅ **Motivation élevée** pour séances

### SIGNAUX AJUSTEMENT NÉCESSAIRE

🚨 **Échecs répétés** Max Effort (>2 séances consécutives)
🚨 **Vitesse diminuée** Dynamic Effort (<0.6 m/s)
🚨 **Fatigue >72h** post-séances
🚨 **Douleur récurrente** hanche ou épaule
🚨 **Perte motivation** persistante
🚨 **Technique se dégrade** systématiquement
🚨 **Sommeil perturbé** régulièrement

**Action si signaux rouges :** Deload immédiat ou consultation coach/médecin
